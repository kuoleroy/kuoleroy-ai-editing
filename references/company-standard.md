# 公司 AI 剪辑标准（执行前必读）

> 适用：医生数字人口播 / 医疗科普竖屏短视频批量生产。
> 基线值来自公司三条优秀成片实测与多轮用户验收；不同医生参考工程参数优先于本表，偏差须写入验收报告。

## 1. 画布与工程

| 项 | 基线 |
|---|---|
| 分辨率 / 帧率 | 1080×1920 / 30fps |
| 工程形态 | 一条视频一个独立工程；成片与工程分开保存、名称一一对应 |
| 必需轨道 | 视频分镜 / 原声 / BGM / 顶标题 / 字幕 / 免责声明（尽量独立） |
| 必备文件 | `draft_info.json` 或 `draft_content.json`、`draft_meta_info.json`、`draft_cover.jpg` |
| 可编辑性 | 标题、字幕不得烧死在画面；素材引用路径有效，无大量红色缺失 |

## 2. 画面参数

| 参数 | 值 | 说明 |
|---|---|---|
| 顶标题位置 | `transform_y = 0.84 ~ 0.86` | 约画面顶部 7%；`0.42` 为历史错误值（压到人物眼睛） |
| 顶标题样式 | 黄底黑字 / 黄色圆角胶囊底，全片常驻 | 剪映字号 12–13；渲染链路 78→94px；圆润字体优先 |
| 顶标题文案 | 吸引点击的问句，精简，不出现药名 | 例「前列腺增生是怎么来的？」 |
| 字幕位置 | `transform_y = -0.14 ~ -0.20`（胸口，画面 y≈58%–60%） | 严禁放到腹部 y≈71%–75% |
| 字幕字号 | 剪映 10–12（基线 12）；渲染链路 110px | 两套单位不同，不要混用 |
| 免责声明 | `transform_y ≈ -0.91 ~ -0.93`，剪映字号 5 / 渲染 52px，两行全片常驻 | 合规声明按团队统一模板 |
| 数字人缩放 | 1.18（标准版）/ 1.08（简化版） | 按医生风格卡 |
| 画中画缩放 | 0.5（小窗）/ 0.8（重点） | 竖屏化用模糊背景填充 |
| 平均片段时长 | **1.7–2.4 秒** | 旧标准 3–5 秒已废弃 |
| 美颜 | 磨皮 70% + 粉白 35%；增强档 84% + 42% | 只作用于医生口播片段 |
| 插入素材 | 每条 ≥3 处，建议 5 处，开头最重要 | 语义匹配、竖屏化、静音、清除硬字幕、不重复 |

## 3. 音频参数

| 参数 | 值 |
|---|---|
| 口播响度 | loudnorm 标准化到 -16 LUFS，峰值 -1.3 dB |
| BGM 音量 | **6%–19%**（旧 20%–25% 废弃）；淡入 1s / 淡出 1.5s |
| 音效 | 每条 12–26 个，音量 100%，落在字幕切换与重点词 |
| BGM 选择流程 | AI 给 4–5 首候选（30s 试听片段）→ 用户试听选定 → 才加入渲染 |
| 主题匹配 | 睡眠类舒缓；前列腺类节奏稳健；中老年受众可用老歌伴奏 |
| 语速修正 | 按单条反馈调整（例：0.9 倍），同步重建字幕时间轴 |

## 4. 字幕硬规则

1. 文本**逐字来自逐字稿**，只去标点与口头语，不改写、不增删字；ASR 场景按医学词表校正。
2. 单行显示，每行 **≤11 字**，**无标点**；默认按原文标点/语义停顿断句，一行一个语义片段、不跨句拼接；长句在同一语义单元内均衡切分，禁止机械切成一字一条。`build_subtitles.py --merge` 可跨标点合并短片段以减少字幕行数，但需人工复检语义。
3. 保护词（成语、辨证名词、专有短语，如「下焦湿热」「气血亏虚」）不得切分、不得跨画面；切素材点必须在句子边界之后。
4. 时间轴来自 **ASR 词级时间戳 + 逐字稿强制对齐**；禁止按字数估时。
5. 首句对齐口播实际起点；末句结束时间延长到视频结尾后 **0.6 秒**；相邻事件**无重叠**。
6. 关闭剪辑器「自动换行」（历史事故：换行宽度 0.82 导致每字竖排）。
7. 交付 `.ass` / `.srt` / 字幕 JSON 中至少两份，附机器质检结果。

## 5. 封面

| 项 | 规范 |
|---|---|
| 尺寸 | 1080×1920 |
| 结构 | 底图 + 人像抠图白边 + 超大主题字 + 黄色两行标题 + 半透明横条 |
| 文字 | 放进灰框/蓝灰横条并垂直居中；两行黄字同号（80px）；加阴影避免发素 |
| 人像 | 放大上移、整体居中，横条不得遮住人像；站姿半身照最佳 |
| 文案 | 按主题提炼，精简、**不出现药名**；无模板时按账号既有底图风格复刻 |

## 6. 输入规范（五文件夹）

```
<项目目录>/
├── 封面模板/    账号过往封面（学习版式，替换主题文案）
├── 工程文件/    该账号优秀工程（按医生分别建风格卡）
├── 数字人原片/  主轨 + 声音来源
├── 素材/        与文案匹配的补充画面
├── 文案/        逐字稿（字幕唯一文本依据）
└── 输出/        成片/封面/字幕/plan.json/剪辑说明/验收报告
```

缺项处理顺序：报告缺项 → 团队素材库检索 → 复制到个人素材库 → 外部可商用来源补足 → 记录素材来源。

## 7. 命名与版本

| 对象 | 规则 | 示例 |
|---|---|---|
| 成片 | `日期-XXX医生——主题`，主题 ≤6 字 | `2026-10-22-示例甲医生——前列腺增生-三改.mp4` |
| 封面 | `XX医生名字-主题` | `示例甲医生-前列腺增生.jpg` |
| 工程 | 与成片一一对应，可加 `-可编辑工程` / `-样板v3` | `2026-10-24-示例乙医生——前列腺增生-样板v3` |
| 改版 | `-一改` / `-二改` / `-三改`，旧版全部保留 | 不覆盖、不删除 |
| 目录 | 成片 `<OUTPUT>\<批次>`；工程 `<DRAFTS>` | 换机先做环境自检，不硬编码 |

## 8. 素材库与权限

- 团队公共盘（D 盘）**只读**：只复制，不修改，不直接在公共盘上剪辑。
- 个人素材库建在 G 盘，按病症分类（失眠睡觉 / 情绪 / 前列腺 / 检查 / 美食 / 生活场景 / 大脑…）。
- 外部下载素材同样入库分类；带平台硬字幕的素材须裁切或插值清除。
- 每次交付记录素材来源，避免同批素材反复复用。

## 9. 交付清单

- [ ] 独立可编辑工程（已注册、剪映首页可见、回读通过）
- [ ] 可预览 MP4 成片
- [ ] 封面 1080×1920
- [ ] `plan.json` 任务单 + `.ass`/`.srt` 字幕 + 字幕质检结果
- [ ] 剪辑说明（改动、参数、素材插入点、BGM、可优化点）
- [ ] 验收报告（工程回读 + 字幕质检 + 关键帧对照）
- [ ] 历史版本完整保留

## 10. 验收清单

**工程**：能打开；一条一工程；轨道独立；标题字幕未烧死；素材路径有效；时长与成片一致；坐标 `0.84 / -0.20 / -0.91`；解密回读通过。

**字幕**：单行；≤11 字；无标点；无重叠；末句完整；语义短句不跨画面；首句对齐；文本逐字来自逐字稿。

**画面**：顶标题全片常驻且不压人物；字幕在胸口不溢出；插入素材 ≥3 处且开头有；素材不重复、无硬字幕重叠；美颜只作用于医生画面。

**音频**：响度正常；BGM 为用户确认曲目、音量 6%–19%、有淡入淡出；语速按单条修正。

**文件**：命名合规；版本未覆盖；五类交付齐全；公共盘未被修改。

## 11. 流程纪律

- 先剪 1 条样板 → 用户验收通过 → 才批量处理其余视频。
- 每次学习参考工程按「第 01 批 / 第 02 批」编号沉淀风格卡。
- 同类修改出现 3 次以上（三次法则），升级为团队参数并更新本文件。
- 角色分工：AI 剪辑运营每周归类修改点、更新参数库、出周报；负责人只定标准、审片、决定哪些修改固化。
