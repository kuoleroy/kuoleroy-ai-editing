# 历史故障与排错（真实案例，按出现频率排序）

> 原则：先定位根因再改；改完回读工程 + 做字幕质检 + 抽关键帧对照成片。
> 不用「看起来差不多」当验收，尤其不要只看 FFmpeg 预览——历史上多次是预览与工程两套参数不一致。

## 1. 字幕 / 音画

| 现象 | 根因 | 修正 |
|---|---|---|
| 剪映导出后字幕变成一列竖排大字 | 开启剪映「自动换行」且换行宽度设 0.82，剪映按极窄宽度每字强制换行；FFmpeg 预览走另一套排版所以没暴露 | 关闭自动换行、改手动换行；标题字号回到 12；**必须用剪映导出效果验收** |
| 字幕比人声慢 / 字 音 对不上 | 按字数估时、手动把 46 句压成 25 句导致映射偏差 | 改用 Whisper 词级时间戳 + 逐字稿强制对齐；首句从口播实际起点出现；样板从 61 条重组为 47 条语义短句 |
| 最后一句字幕没了 | 末条结束时间早于视频结尾 | 延长到视频结尾后 0.6 秒 |
| 批量出现逐字闪字幕 | 切行算法偏向短片段 | 按标点停顿并在 11 字内均衡切分，重渲染全部 |
| 相邻字幕重叠 | 事件边界未去重叠 | 生成后做重叠检测并修正 |
| 关键短语跨画面（「下焦湿热」「这是很常见的气血亏虚」） | 字幕切分与素材切换未保护专有短语 | 建立保护词表 + 镜头区间约束，切素材点落在句子边界之后 |
| 预览渲染丢一条字幕 | 单步合成在 19–22 秒丢事件 | 先出无字幕成片，再单独叠加字幕（两步渲染） |
| 医学术语错字 | ASR 直出未校正（「丝状油」→「丝状疣」、「米克莫特」→「咪喹莫特」） | 维护医学词表，逐条校正 |
| 字幕位置不对（腹部、溢出、顶到屏幕） | 坐标单位/链路混用 | 统一胸口 `transform_y=-0.20`；渲染链路 110px 与剪映 12 号分开记 |
| 后段字幕整体飘走 | 长音频单次转写只覆盖前半段，旧脚本按平均时长外推补齐时间轴 | 分块 25s 窗 / 20s 步长合并词级时间戳；v1.1 起覆盖不足直接 FAIL、禁止外推 |
| 医学术语校正后时间轴错位 | 旧脚本按字符序号硬映射，逐字稿与 ASR 不等长即整体漂移 | v1.1 起做字符级序列对齐，差异记入 `alignment.differences`，人工复核后显式放行 |
| 「对是嗯」跨句拼接 / 逐字闪字幕 | 碎片合并跨了标点；口头语未从逐字稿删除 | v1.1 起只在句内合并，单字行判不合格；口头语在逐字稿阶段人工删除 |

## 2. 工程 / 画面

| 现象 | 根因 | 修正 |
|---|---|---|
| 剪映里找不到昨天剪的片 | 11 条批量片由 Python + FFmpeg + ASS 直接生成 MP4，没有生成剪映草稿 | 补齐独立可编辑工程并注册索引；**成片导出方式不限，但工程必须存在** |
| 草稿目录找不到 | 实际草稿在 `<DRAFTS>`，不是 C 盘默认目录 | 先扫描真实草稿目录，再查 `root_meta_info.json` |
| 剪映里标题压到人物眼睛 | 成片 ASS 用「顶部边距 140px」（约顶部 7%），工程用 `transform_y=0.42`（约顶部 29%） | 统一 `transform_y=0.84 ~ 0.86`；字幕 `-0.20`；免责 `-0.91` |
| 改工程时文件被占用 | 剪映界面已关但后台驻留进程未退 | 改前检测进程；遇文件锁冲突立即停止，生成独立新工程，不覆盖 |
| 注册索引被权限拦截 | `root_meta_info.json` 在 C 盘 AppData 不可写 | 保留工程本体，靠剪映扫描草稿目录或用「导入草稿」 |
| 加密草稿在另一台机器读不出 | 草稿加密依赖本机 `videoeditor.dll` | 本机整体拷贝草稿文件夹并用本机工具解密，不要跨机打包还原 |
| 工程打开大量红色缺失素材 | 素材路径失效 / 直接引用公共盘 | 素材复制到个人素材库，工程引用稳定本地路径 |
| 素材自带硬字幕与新字幕重叠 | 引用平台素材含硬字幕 | 固定区域裁切 / 边缘插值清除 / 打码 |
| 图片素材缺失导致风格学不全 | 工程里只记录了路径 | 先学已有工程与成片，明确列出缺口清单，后续补齐再迭代 |

## 3. 素材 / BGM / 版本

| 现象 | 根因 | 修正 |
|---|---|---|
| 素材反复重复使用 | 未建立分类素材库、未做来源记录 | 建 G 盘个人素材库按病症分类；每条记录素材来源与插入点 |
| 公共盘被误改 | 直接在 D 盘公共库剪辑 | D 盘只读复制，绝不写入 |
| BGM 太吵 / 太年轻欢快 | 音量按旧标准 20%–25%，曲风未过用户确认 | 音量 6%–19%；先给 4–5 首 30s 候选让用户试听选定再渲染 |
| 原版被覆盖找不回 | 修片时直接覆盖同名文件 | 严格 `-一改/-二改/-三改`，旧版全部保留 |
| 单条语速过快 / 构图顶头 | 统一模板掩盖单条差异 | 建立单条修正表（语速 0.9 倍、人物下移、短语保护、区域打码） |

## 4. 环境与流程

| 现象 | 根因 | 修正 |
|---|---|---|
| Chrome / 桌面自动化不可用 | 沙箱多进程通道受限 | 与剪辑主线无关，不写入教程；剪辑走工程文件驱动 |
| 工具链突然失效 | 工作目录被移动/清理（曾从 Documents 移到 `<TOOLS>`） | 每次开工先做环境自检，路径不硬编码 |
| 剪映自动导出不可用 | 剪映 11.x 取消脚本可控导出控件 | 导出方式不限；工程回读 + 另存成片 |
| 团队另一台机器复现不了 | 只发提示词没发工具包 | 提示词必须与 `jianying-skill` / 便携 Python / FFmpeg 一起分发，且部署后实测生成最小工程 |
| 无法写按钮级教程 | 截图/录屏未覆盖菜单、时间线、字幕面板 | 只写文件与脚本驱动流程，界面细节标注「待确认」 |
| 大素材库扫描卡住（905 个 mp4 约 33 秒） | 对每个文件逐个 ffprobe | 两阶段：全库只扫文件名建索引（约 19ms），只对最终入选的 3–5 个探测；`--include` 按主题收窄 |
| 纯文件名语义挑错素材（「三伏天/人多/长沙地铁」被选中） | 单字交集打分，「天/人/一」等高频字误命中 | 主题 2-gram 匹配 + 停用字过滤 + 逐字稿全文作上下文；不要用单字交集排全库 |
| 明文工程在剪映 11.7 可能打不开 | 11.7 现存 `draft_content.json` / `draft_meta_info.json` 均为加密内容，`pyJianYingDraft` 写出明文 | 首次换机必须按 `输出/工程构建/剪映打开验证.md` 人工打开确认；脚本 `ok:true` 只代表工程结构正确 |
| 插进去是静帧图片却显示通过 | 素材类型写 `photo` 或抽帧当视频 | 相邻两帧 framemd5 比对（`motion.status=moving`）+ 回读审计 `type=video` / `volume=0` / 有 `source_timerange` |

## 5. 排查顺序（推荐）

1. 先确认交付物形态：是「只有 MP4」还是「MP4 + 独立工程」。
2. 再查字幕：条数、单行、字数、标点、重叠、末句、首句对齐。
3. 再查坐标：顶标题 / 字幕 / 免责声明三条链路是否用同一套单位。
4. 再查素材：路径有效性、硬字幕、重复、公共盘是否只读。
5. 最后查环境：剪映版本、草稿目录、加密组件、索引注册、进程占用。
6. 每修一项，重做回读验收并保留新版本，不覆盖旧版。
